SALARY & BUDGET PLANNER v36

DEPLOYMENT
1. Extract this ZIP and upload/replace all files in the same GitHub Pages repository.
2. Commit the changes and wait for GitHub Pages to publish.
3. Open the app and sign in with your existing account.
4. New accounts must complete the initial setup, including at least one working day
   and the weekly duty schedule, before accessing the payroll dashboard.
5. Existing accounts continue directly to the dashboard. Use Restart Setup beside
   Sign out only when you want to repeat the setup.

SUPABASE
No new SQL changes are required for this interface update. Keep the existing
Supabase table, policies, Realtime settings, project URL and publishable key.
Do not share or place a Supabase service-role key in the browser app.

WHAT'S UPDATED IN v36
- Weekly Work Schedule is now under General Information.
- Weekly schedule is included in the required first-time account setup.
- The weekly schedule editor can be opened from setup and from General Information.
- The date-tap attendance editor has a cleaner responsive dialog layout.
